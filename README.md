# NAGMA 홈페이지

주식회사 나그마 기업 홈페이지 (정적 사이트)

## 구성

| 페이지 | 내용 |
|---|---|
| `index.html` | 메인 — 슬로건 · 철학 · 사업영역 · LIFE · NEWS |
| `about.html` | 회사소개 — 사명 · 비전 · RISH · 공간과 활동 |
| `team.html` | 조직도 · 5개 조직 소개 |
| `work.html` | 메디컬 전문 · IT 솔루션 · 영상 콘텐츠 · 브랜드 디자인 |
| `news.html` | 소식 (단일 피드) |
| `contact.html` | 주소 · 지도 · 오시는 길 |
| `privacy.html` | 개인정보처리방침 |

## 기술

- 정적 HTML / CSS / Vanilla JS (빌드 도구 없음)
- 폰트: Pretendard(국문) · Sora(영문) — CDN
- 그래픽: Canvas 2D 기반 코드 그래픽 6종 (이미지 파일 아님)

## 로컬 실행

```bash
python3 -m http.server 8899
```
